# Педагополія — онлайн-версія

Це повноцінний **самостійно розгортуваний вебзастосунок** з Node.js-сервером. Він не потребує npm-залежностей. Сервер зберігає кімнати та прогрес у `rooms.json`, видає коди кімнат і синхронізує стан учасників через опитування API кожні ~2,3 секунди.

## Локальний запуск

1. Встановіть Node.js 18+.
2. Відкрийте термінал у цій папці.
3. Виконайте `npm start`.
4. Відкрийте `http://localhost:3000`.

## Публікація

Створіть вебсервіс у Render / Railway / іншому Node.js-хостингу з цієї папки або Git-репозиторію. Команда запуску: `npm start`. Порт береться зі змінної середовища `PORT`. Для **надійного збереження** кімнат потрібен постійний диск: змінна `DATA_FILE` має вказувати на шлях на persistent volume (наприклад, `/data/rooms.json`). Без такого диска кімнати можуть зникнути після перезапуску чи повторного розгортання. Потрібен один серверний процес (не декілька реплік).

## Важливі обмеження

- Підключення з різних пристроїв працює після розгортання на одному доступному HTTPS-сервері. Зараз публічний URL не створено.
- Викладач і гравці мають приватні токени доступу, що зберігаються у localStorage браузера. Це навчальний MVP, а не система персональних облікових записів.
- Голоси інших гравців не віддаються через API; після підрахунку видно лише кількість голосів за варіанти. Немає повноцінного аудиту безпеки, захисту від багаторазових входів чи механізму відновлення доступу.
- Таймер і прогрес синхронізуються через серверний час, а не вебсокети.
- Педагогічні ситуації мають по три варіанти, у вихідному банку правильний варіант перший. Перед публічним навчальним використанням слід перемішати варіанти й відредагувати кейси з викладачем.
- Для великого навантаження або виробничого використання рекомендовано перенести дані до PostgreSQL, додати HTTPS, rate limiting, облікові записи, резервне копіювання, тестування та моніторинг.


## Оновлення v8 — навчання та економіка
- Кожна **нова** школа починає з 0 монет. Для реформ спершу проходьте тести або педагогічні ситуації.
- Вбудований покроковий туторіал відкривається при першому вході в кімнату; кнопка «❔ Як грати» дозволяє повторити його будь-коли.
- Для педагогічної комісії та гравців є окремі інструкції.
- У вже створених кімнатах старий бюджет зберігається; для перевірки нового старту створіть нову кімнату.


## Версія 10 — стрічка новин школи

У розділі «📰 Новини школи» з’являються повідомлення про впроваджені реформи, нових учнів, рішення щодо нагальних ситуацій та початок раундів. Поруч показані сценарні реакції персонажів: радість, запитання й нові прохання. Новини зберігаються у стані кімнати та синхронізуються між гравцями через сервер. Для старих кімнат стрічка почне заповнюватися після наступної дії. Реакції є навчальним сценарієм, а не психологічним вимірюванням.
